    Methodology

    Prices are list prices from the OpenRouter models API, pulled once a day by a scheduled job and stored as dated snapshots. Changes are detected by diffing consecutive snapshots. For first-party models this matches the lab's own API list price.

    Blended $/1M = (uncached input × input price + cached input × cache-read price + output × output price) ÷ total tokens, using the workload above. Long-context surcharges (e.g. above 272K prompt tokens) are shown in model detail but not used in the blend.

    By default the page hides batch tiers, free endpoints, rolling "latest" aliases and router models with variable pricing. List prices only: no volume discounts, enterprise deals or throughput and quality adjustments.
